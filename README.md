# 服づくりプランナー

作りたい服の種類・サイズ・生地を指定すると、次をまとめて出力する Next.js (App Router / TypeScript) アプリです。

- 型紙(製図)… パーツごとに仕上がり線・縫い代線・布目・わ・ダーツを表示。実寸(1cm=1cm)SVGで保存可能
- 必要布量 … 布幅ごとの必要量(水通し縮み・柄合わせ・予備込み)
- 副資材 … 接着芯・糸・針・ファスナー・ボタン・ゴム・バイアステープなど
- 裁断配置図 / 作り方の流れ(チェックリスト付き)
- 概算費用・難易度と所要時間の目安・必要な道具・生地ごとの扱い方(アイロン温度/縫い目/始末)
- A4分割の原寸印刷(トンボ・のりしろ・5cm角の原寸確認付き)
- 作る枚数・仮縫い(トワル)用シーチングの計算、設定の共有リンク、自動保存
- ガイド(採寸のしかた・ゆとり・針と糸・縫い代・アイロン・用語集)
- 体型補正: なで肩/いかり肩・前後の身幅バランス・前丈/後ろ丈・上腕・首まわり・出尻/平尻・お腹・太もも(製図の線そのものを補正)
- サイズ: レディース / メンズ / キッズ(80〜140cm・目安)

対応(7ジャンル・34種類):
- トップス: Tシャツ / 長袖Tシャツ / タンクトップ / シャツ / 半袖シャツ / オーバーサイズシャツ / スウェット / パーカー / カーディガン / ベスト
- パンツ: パンツ / ワイド / ハーフ(ゴム) / ショート / イージー / ガウチョ
- スカート: 台形 / タイト / ミニ / サーキュラー / セミフレア(半円) / ギャザー / ティアード
- ワンピース: ノースリーブ / 半袖 / ロング / チュニック / シャツワンピース
- アウター: ジャケット / コート / ロングカーディガン
- 和装: 浴衣(直線裁ち) / 甚平(上衣)
- 小物: エプロン

## 使い方

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番ビルド(dev 起動中は実行しないこと。.next が壊れます)
npm run check    # 全アイテム×全サイズ×全生地の自動検査
```

## Vercel へデプロイ

1. このフォルダを GitHub 等にpush し、Vercel で「Add New → Project」から取り込む(設定は自動検出・変更不要)。
2. または `npx vercel` / `npx vercel --prod`。

サーバー機能・環境変数は不要の静的+クライアント計算アプリです。

## 構成

| パス | 役割 |
| --- | --- |
| `lib/garments/*.ts` | 各服の製図ロジック(ここに服を追加)。`variants.ts` は既存の型紙の初期値違い(ワイドパンツ等) |
| `lib/garments/common.ts` | 身頃・袖の共通ドラフト(文化式原型を簡略化) |
| `lib/estimate.ts` | 布の配置(シェルフ法)・必要量・副資材の算出 |
| `lib/data.ts` | サイズ表・生地プリセット |
| `lib/svg.ts` | 型紙/裁断図のSVG生成 |
| `components/Planner.tsx` | UI |

### 服を追加するには
`lib/garments/` に `GarmentDef`(`params` と `build`)を返すファイルを作り、`lib/garments/index.ts` の `GARMENTS` に追加します。`build` は座標(cm)のパーツ配列・副資材・手順を返すだけです。

## 注意

- 型紙は簡易ドラフトです。本縫い前にシーチング等で仮縫いして調整してください。
- 必要布量は各パーツを縫い代込みの長方形として詰めた概算です(実際はこれより短くなることがあります)。
- サイズ表はJIS等を参考にした目安値で、メーカーにより異なります。
